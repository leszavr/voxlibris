## Обзор

Email-шаблоны используются для отправки уведомлений пользователям и администраторам. Все шаблоны находятся в директории `email-templates/`.

## Структура шаблона

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>{{subject}}</title>
  <style>
    /* Inline styles for email clients */
  </style>
</head>
<body>
  <div class="container">
    <h1>{{title}}</h1>
    <p>{{message}}</p>
    <a href="{{actionUrl}}" class="button">{{actionText}}</a>
  </div>
</body>
</html>
```

## Переменные

### Общие переменные

| Переменная | Описание | Пример |
|------------|----------|--------|
| `{{userName}}` | Имя пользователя | "Иван" |
| `{{userEmail}}` | Email пользователя | "user@example.com" |
| `{{appName}}` | Название приложения | "VoxLibris" |
| `{{appUrl}}` | URL приложения | "https://voxlibris.ru" |

### Специфичные переменные

#### Регистрация

| Переменная | Описание |
|------------|----------|
| `{{confirmationUrl}}` | Ссылка для подтверждения |
| `{{confirmationCode}}` | Код подтверждения |

#### Сброс пароля

| Переменная | Описание |
|------------|----------|
| `{{resetUrl}}` | Ссылка для сброса пароля |
| `{{resetCode}}` | Код сброса |

#### Клубы

| Переменная | Описание |
|------------|----------|
| `{{clubName}}` | Название клуба |
| `{{clubUrl}}` | URL клуба |
| `{{inviterName}}` | Имя пригласившего |
| `{{rejectionReason}}` | Причина отклонения |

## Тестирование

### Отправка тестового письма

```bash
# Тест SMTP
pnpm run test:email

# Тест конкретного шаблона
pnpm run test:email --template=registration-confirmation
```

### Проверка рендеринга

```bash
# Генерация HTML для проверки
pnpm run email:render --template=club-invitation
```

## Добавление нового шаблона

1. Создать HTML файл в `email-templates/`
2. Добавить в список выше
3. Добавить тест в `server/__tests__/email.test.ts`
4. Обновить документацию
